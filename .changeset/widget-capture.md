Add the capture form: a textarea focused on open, type chips (`types`), `Ctrl/Cmd+Enter` to submit and a confirmation toast. Each note records the page (url, route, title, referrer, viewport, user agent, colour scheme, timezone), the text selected when the widget opened, `environment`, `author` and the host's `context()`. Opt-in `consoleErrors` attaches recent errors. Drafts persist in `localStorage`.
