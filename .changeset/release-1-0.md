First release. field-notes captures feedback in context, in any web app: a drop-in `<field-notes>` widget opened from a hotkey, a floating button or your own UI, with an element picker, screenshots and an offline outbox. Notes land as plain files in your project through the Vite plugin, the Node middleware or `field-notes serve`, or travel as an exported zip. The `field-notes` CLI lists, shows, tails, exports, imports and prunes them.
